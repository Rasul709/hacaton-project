# 🧠 Проектная память (Project Memory) — Digital HR by Jana Post

> Этот документ сохраняет ключевые договоренности, архитектурные решения, бизнес-правила и историю разработки проекта для ИИ-ассистентов и команды.

---

## 📅 Хронология ключевых этапов
1. **Инициализация:** Создан проект на React 19 + TypeScript + Vite + Tailwind CSS v4 с дизайн-системой Jana Post.
2. **Базовый MVP:** Реализован дашборд с аналитикой (Recharts), справочники отделов, каталог сотрудников и трекер посещаемости (Clock In / Clock Out).
3. **Локализация под РК:** Настроен учет времени в часовом поясе **UTC+5 (Алматы/Астана)**, базовая квота отпусков **24 дня** (по ТК РК), типовые кадровые печатные формы (Т-2, Т-6, Т-13), экспорт в Excel/CSV с UTF-8 BOM.
4. **Хакатон-модули:**
   - **Jana Academy (LMS):** Интерактивные курсы онбординга, уроки и тесты с начислением баллов.
   - **HR AI-Ассистент:** Корпоративный RAG-консультант по Трудовому кодексу РК и внутренним регламентам Jana Post.
   - **Личный кабинет сотрудника:** Персональный виджет баланса отпусков, быстрых заявок и табеля.
   - **Мастер-презентация:** Интерактивный режим презентации на 30 слайдов с таймером и режимом полного экрана.
5. **Централизация в Antigravity:** Проект консолидирован в каталоге `HR-Digital` со всеми базами данных, схемами, правилами и памятью.

---

## 🎯 Бизнес-правила и требования
* **Часовой пояс:** Строго `UTC+5` (единый часовой пояс Казахстана с 1 марта 2024 года).
* **Кадровый учет:**
  * Отпуск: минимум 24 календарных дня.
  * Учет рабочего времени: стандартная 40-часовая рабочая неделя.
  * Переработки: фиксация сверхурочных часов.
* **Ролевые модели (RBAC):**
  * `admin` — Айгерим Смагулова (полный доступ, согласование отпусков, аналитика).
  * `manager` — Бауыржан Касымов (руководитель отдела логистики, контроль смен, задачи).
  * `employee` — Адиль Омаров (разработчик, подача заявок, личный табель, курсы).

## 🔒 Безопасность и хранение данных
* В режиме демонстрации данные хранятся изолированно в `localStorage` браузера (`jp_mock_*`).
* Кнопка сброса демо-данных в верхнем баннере возвращает эталонное состояние.
* Поддерживается бесшовное переключение на Live REST API.
